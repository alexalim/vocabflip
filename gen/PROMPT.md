# 영단어 카드 콘텐츠 생성 규격

입력 JSON 배열의 각 단어마다 한국인 학습자용 카드 콘텐츠를 만든다.
입력 항목: `w`(표제어), `lvl`(빈도 등급), `forms`(BNC/COCA 원본의 파생형, 빈도순).

## 출력
입력과 **같은 순서, 같은 개수**의 JSON 배열을 지정된 출력 파일에 쓴다(UTF-8, 다른 텍스트 없이 JSON만).

```json
{
  "w": "abort",
  "pos": "v",
  "meaning_ko": "중단하다, 중지시키다",
  "example_en": "We had to **abort** the whole plan when it started raining.",
  "example_ko": "비가 오기 시작해서 계획을 통째로 접어야 했어.",
  "nuance_ko": "abort는 이미 시작한 걸 도중에 끊어버린다는 말이에요. ...",
  "also": [
    {"w": "abortion", "pos": "n", "ko": "낙태, 유산", "en": "They argued about **abortion** all night."},
    {"w": "abortive", "pos": "adj", "ko": "실패로 끝난", "en": "It was an **abortive** attempt to fix things."}
  ]
}
```

## 필드 규칙
- `pos`: 가장 대표적인 품사 하나. `n`, `v`, `adj`, `adv`, `prep`, `conj`, `pron`, `det`, `int`, `num` 중에서 고른다.
- `meaning_ko`: 핵심 뜻 1~3개를 쉼표로 구분한다. 사전식 나열은 하지 말고 가장 많이 쓰는 뜻을 앞에 둔다.
- `example_en`: 원어민이 실제로 할 법한 자연스러운 한 문장(대화체 우선, 8~16단어). 표제어(또는 그 굴절형)를 `**`로 한 번 감싼다.
- `example_ko`: 번역투가 아닌 자연스러운 구어체 번역.
- `nuance_ko`: 4~6문장, 해요체로 친근하게 설명한다. 다음 중 해당하는 것을 담는다.
  - 이 단어의 핵심 그림(어떤 느낌·상황에서 쓰는지)
  - 비슷한 단어와의 차이(예: abort vs cancel vs stop)
  - 자주 붙는 짝꿍 표현·구문(예: can't afford to ~)
  - 한국 학습자가 자주 틀리는 점
  - 어느 맥락(구어/뉴스/비즈니스/격식)에서 쓰는지

  영어 단어·예시는 그대로 영어로 쓴다. 뻔한 말("중요한 단어예요", "많이 쓰여요")로 채우지 않는다.
  관사·전치사 같은 기능어(a, the, of, about…)는 쓰임의 차이와 실수 포인트를 구체적으로 쓴다.
- `also`: **입력 `forms`에 있는 단어만** 사용한다. 새 단어를 만들지 않는다. 뜻이나 품사가 표제어와 달라지는 파생어를 빈도가 높은 것부터 0~3개 고른다. 단순 굴절형(복수 -s, -ed, -ing, 3인칭 -s, 비교급)은 제외한다. 각 항목은 `w`, `pos`, `ko`(짧은 뜻), `en`(짧은 자연스러운 예문, 해당 단어를 `**`로 감쌈)으로 구성한다. 적당한 파생어가 없으면 빈 배열 `[]`로 둔다.

## 금지
- 사실과 다른 어원·용법을 지어내지 않는다.
- 혐오·성적인 예문을 쓰지 않는다. 민감한 단어라도 중립적이고 사전적인 예문을 쓴다.
- 출력 파일에 JSON 외의 텍스트를 넣지 않는다.
